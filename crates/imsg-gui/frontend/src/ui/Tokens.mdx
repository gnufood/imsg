# Design tokens

Renders the actual atoms and CSS custom properties from `src/` — nothing on this page is a
copied value, so it can't drift from `index.css` (colors), the `Text` atom (typography), or
`ui/atoms/interactive-styles.ts` (states).

`surface`/`ink`/`muted`/`line` swap for dark mode (`prefers-color-scheme`); `accent` is fixed.
`success`/`info` (status-only, used by `StatusDot`) swap for dark mode too. Swatches above follow
whichever mode your system is currently in.

## Typography

Every text node goes through the `Text` atom: `size` (`sm`/`xs`) × `tone` (`ink`/`muted`/`surface`).
No `--font-sans` override lives in `index.css`, so the one font family in use everywhere is
Tailwind's built-in default, applied globally by Preflight — no component ever reaches for a
`font-*` utility.

<div className="flex flex-col gap-3 rounded-md border border-line p-4 font-sans">
  <Text size="sm" tone="ink">The quick brown fox jumps over the lazy dog</Text>
  <Text size="xs" tone="ink">The quick brown fox jumps over the lazy dog</Text>
</div>

<div className="flex flex-col gap-2">
  <Text size="sm" tone="ink">sm / ink — default body text</Text>
  <Text size="sm" tone="muted">sm / muted — secondary text</Text>
  <Text size="xs" tone="ink">xs / ink — small labels</Text>
  <Text size="xs" tone="muted">xs / muted — timestamps, captions</Text>
</div>

clickable/focusable atom below reuses the same tokens instead of hand-rolled duplicates. Tab
through this page to see the shared focus ring; hover/click for the rest.
